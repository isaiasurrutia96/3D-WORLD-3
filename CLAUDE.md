# Instructions for Claude

## Error-prevention rule

The owner's standing rule, to follow every time the game is built or
changed:

1. Before building, restate what I asked for in one or two sentences. If
   anything is unclear, ask first. Don't guess.
2. After every change, run the game in a test browser and take screenshots
   before showing me anything.
3. Screenshot at iPhone portrait size AND desktop size.
4. Take screenshots from at least 3 angles: close behind the character,
   overhead, and a wide view.
5. Compare each screenshot to what I asked for. List anything that doesn't
   match, fix it, and screenshot again.
6. Check for phone problems: keyboard messages, overlapping buttons, debug
   text, cut-off UI, and touch controls that don't work.
7. Check the browser console for errors and fix them.
8. Confirm that nothing I didn't ask to change got changed.
9. Only then show me the result, with the final screenshots and a short list
   of what you checked and fixed.

Also read `AGENTS.md`, which is shared with Codex.
